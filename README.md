# Grüezi — web app and update channels

The web app lives at the root: <https://itamarernst.github.io/gruezi-updates/>

Everything else is what the sideloaded Android builds read to update
themselves. One folder per language, so a release can only ever reach the
build it was meant for:

| Channel | App | Manifest |
|---|---|---|
| `gruezi/` | Grüezi — Swiss German | [manifest.json](gruezi/manifest.json) |
| `ciao/` | Ciao — Italian | published from the `italian` branch |
| `shalom/` | Shalom — Hebrew | published from the `hebrew` branch |

A manifest names the current content files with their SHA-256, and the current
APK — which lives on the [releases page](../../releases), not in this repo, so
the history stays small.

Generated by `tools/publish.py` in the app repo. Don't edit by hand.
